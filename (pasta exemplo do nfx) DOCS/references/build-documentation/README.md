# build-documentation

Documentação de **build, deploy e runtime** do projeto: orquestração (Docker/compose),
jobs one-shot, workers, schedulers, storage e variáveis de execução.

Contexto transversal usado por vários planos. **Manter atualizada** a cada mudança na
infraestrutura de build/execução, para que qualquer plano possa consultá-la como fonte
única da arquitetura de deploy.
