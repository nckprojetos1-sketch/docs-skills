## Objetivo
Registrar o estado oficial do SDDR.

## Regra
- este arquivo é a autoridade de estado do SDDR;
- `01-sddd/` traz o planejamento (prd/spec/dependencies) desta mudança local;
- `reports/` documenta o que foi executado e os handoffs.

## Checklist inicial
- [ ] objetivo definido
- [ ] escopo definido (o que entra / o que fica fora)
- [ ] critérios de aceite definidos (`01-sddd/prd.md`)
- [ ] validações esperadas definidas (`01-sddd/spec.md`)
- [ ] handoff para executor pronto

## Completion gate
- [ ] critérios de aceite atendidos
- [ ] validações executadas com evidência
- [ ] report de execução criado
- [ ] `status: completed`
